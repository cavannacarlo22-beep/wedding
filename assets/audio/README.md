# Traccia musicale

Per attivare la musica di sottofondo, inserisci qui un file chiamato **`music.mp3`**:

```
assets/audio/music.mp3
```

Il percorso è configurabile in `script.js` → `weddingConfig.music`.

Consigli:
- brano strumentale, delicato (pianoforte, archi, chitarra classica);
- durata 2–4 minuti, il player va in loop;
- volume della registrazione non troppo alto: il sito riproduce a volume 0.45;
- formato `.mp3` (massima compatibilità) o `.m4a`, peso consigliato < 4 MB.

**Il file non è incluso nella demo** per motivi di licenza. Se manca, il sito
funziona normalmente: il pulsante musica si disattiva da solo, senza errori in console.
